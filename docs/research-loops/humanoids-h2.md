# Unitree H2 / H2 PLUS review · 2026-10-01

## Identity and scope

H2 PLUS is an official Unitree product and the hardware basis of the announced NVIDIA Isaac GR00T reference. It is not merely a seller name. H2 and H2 EDU share body specifications, but the detailed manufacturer table provides secondary development and additional compute/hand options for EDU. The reviewed EDU base excludes unselected hands and AI modules.

The H2 PLUS review selects the official dual-Sharpa-Wave/T5000/wrist-camera reference: 31 body joints plus two 22-DOF hands gives 75 DOF. Unitree labels hands/cameras optional. Reichelt Smart is a handless package; Ultimate letters identify different hand packages. Ultimate N uses the name Sharpa Hand 2; exact equivalence to Sharpa Wave is not established. Never silently substitute this seller package for the reference configuration.
